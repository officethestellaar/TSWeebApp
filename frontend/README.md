# The Stellaar Frontend

This is the Next.js (App Router) frontend for The Stellaar Management System.

## Theme & Design
This application follows the **Premium "The Stellaar" Theme**:
- **Palette:** Navy (`#0f172a`), Gold (`#c5a059`), Slate (`#64748b`).
- **Typography:** Playfair Display (Serif) for headings, Inter (Sans) for body.
- **Components:** Uses glassmorphism and premium gradients.

## Development
For full system instructions, refer to the [Root README](../README.md).

### Scripts
- `npm run dev`: Start Next.js in development mode.
- `npm run build`: Build for production.
- `npm run lint`: Run ESLint (maintained at 0 errors).
- `npm test`: Run Vitest component tests.
